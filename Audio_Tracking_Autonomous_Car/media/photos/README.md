# Audio-Tracking Car: Prototype Photographs

Photos of the original Group 11 audio-tracking robot prototype from UGA ECSE 2920 (Spring 2025).

The original vehicle photograph is available as [car_prototype.jpg](car_prototype.jpg). It shows the physical breadboard-based prototype, Raspberry Pi control hardware, and two-wheel chassis—not a manufactured custom PCB assembly.

See the [project overview](../../README.md), [technical documentation](../../docs/Technical%20Documentation%20-%20Group%2011.pdf), and [system signal diagram](../signal_chain.svg).
